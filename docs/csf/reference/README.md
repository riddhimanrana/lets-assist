# CSF reference workbook

`c-o-2028-synthetic.xlsx` is a from-scratch, privacy-safe reference for the legacy class-officer term ledger. It intentionally contains no source workbook metadata, comments, hidden payloads, real names, email addresses, phone numbers, provider identifiers, or copied activity text.

The workbook preserves the useful contract:

- eight term tabs in order: `S28`, `F27`, `S27`, `F26`, `S26`, `F25`, `S25`, `F24`;
- the original term-specific activity and meeting column shapes;
- header-only future templates and populated historical examples;
- formula-derived `LastFirst`, meeting-attendance, and requirement-completion cells;
- green, yellow, and red ledger states for complete, pending, and incomplete examples;
- the historical populated sheet dimensions (`S26` 168 rows, `F25` 194, `S25` 130, and `F24` 164).

All member identities use deterministic `Synthetic-NNN` / `Member-NNN` labels. Activities are generic fictional examples. The workbook was rendered and visually reviewed sheet by sheet, and its formulas were scanned for spreadsheet error values before tracking.

This file is documentation and parser/reference input only. It is not an authoritative roster, a migration source, or Production evidence.
